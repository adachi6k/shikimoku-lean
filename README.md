# 御成敗式目の形式化と衝突候補の検証

御成敗式目の原文翻刻をもとに、AIが条件付きの規則と裁判手続のモデルを作成し、Lean 4で検査するデモです。原文照合版は全51条から採録した規則同士の重なりを、手続版は8条に関わる手続の適用順序を調べます。原文の全内容を形式化したものではありません。

## 実行方法

[公式のインストール手順](https://lean-lang.org/install/)に従ってLeanを導入し、以下を実行します。`lean-toolchain` でLean 4.19.0を指定しており、初回はその取得にインターネット接続が必要です。モデルはLean標準の機能だけで動作します。

```bash
git clone https://github.com/adachi6k/shikimoku-lean.git
cd shikimoku-lean
lean --version
lean ShikimokuOriginalAudit.lean
lean ShikimokuProcedureAudit.lean
```

GitHubの **Code → Download ZIP** から取得した場合は、展開したフォルダーのうち `lean-toolchain` がある場所で、`lean --version` 以降を実行します。各モデルは `#eval` で結果を表示し、`#guard` で件数や個別の条件分岐などを検査します。エラーなく終了すれば、登録した検査項目を通過しています。実行結果の詳細は下の報告書にあります。

## ファイルと結果

| Leanファイル | 対象と結果 | 報告書 |
|---|---|---|
| [ShikimokuOriginalAudit.lean](ShikimokuOriginalAudit.lean) | 全51条から160規則を採録。条件分岐を区別した衝突候補は5件、条文番号の組合せでは4組。 | [原文照合版の報告](reports/ShikimokuOriginalAuditReport.txt) |
| [ShikimokuProcedureAudit.lean](ShikimokuProcedureAudit.lean) | 8条の手続について1,024通りの事案を探索。仮定した裁定の留保基準に合わない経路がある事案は、設定により96件・64件・0件（内訳は下記）。 | [手続検証の報告](reports/ShikimokuProcedureAuditReport.txt) |

原文照合版の「衝突候補」は、同じ行為について禁止と義務・許可・慣行が同時に適用できるとモデルが判定した組です。第8条と第43条の間、および第10条・第41条・第48条それぞれの内部に候補があります。第41条は男子・女子を別々に数えるため、4組に対して候補は5件となります。原文や当時の運用に矛盾があると確定したものではありません。

手続版では、第29条を「奉行人を迂回したことが判明した後、留保の解除まで裁定を見合わせる」と読む基準を共通に置き、次の三つの設定を比較します。

| 第29条による裁定の留保をどう扱うか | 共通基準に合わない経路がある事案数 |
|---|---:|
| 第35・49条の直接裁定は認め、出頭後の通常裁定を留保する | 96 |
| 原告への裁許だけを留保し、原告の請求を認めない裁定や他人への給付は認める | 64 |
| 直接裁定を含むすべての裁定を留保する | 0 |

これらは、モデルで条件を組み合わせた1,024通りの事案の件数です。歴史上の事件数や、矛盾する条文の数ではありません。共通基準との差を調べる検査であり、0件となる設定が歴史的に正しい解釈だと示すものでもありません。

## 検証範囲

原文照合版は、160規則に、比較する行為をそろえるために元の規則から生成した4つの効果（比較用効果）を加え、計164項目を扱います。異なる2項目を選ぶ全13,366組を走査し、そのうち同じ行為名で、禁止と義務・許可・慣行が対になる12組について適用条件を比較します。実行結果の「反対モード」は、この禁止と義務・許可・慣行の対を指します。

原文翻刻からの行為名・条件の抽出と、比較対象となる効果の対応づけはAIが行っています。Leanモデルには、異なる表現の同義関係、条件間の含意、義務同士の両立不能、主体や対象の同一性を一般的に推論する仕組みはありません。第41・43条の比較用効果は元の規則から生成し、例外も引き継ぎます。第38条の名主職改替と第45条の糺決要件など、他条への手続条件の接続は未実装です。全51条の採録は、原文の全規範や全事案を検証し尽くしたことを意味しません。

手続版の対象は第6・7・29・35・44・45・49・51条です。第44条の競望と本案を分け、第49条の証拠の明白さと、原告の主張に理があるかを区別します。第29条は、奉行人を迂回した事実、その発覚、留保の発動を別に扱います。発覚時点や留保解除、問状と召文の接続、所職改替の順序にはモデル上の仮定があります。探索は登録した有限の事案・状態・遷移について行い、発覚前の裁定や外部判断による留保解除も含めた範囲を報告書に記載しています。

検証結果は、採用した解釈と、モデルに記述した規則・手続・検査項目に依存します。AIによる原文の解釈やモデルへの変換の正しさ、原文の全内容を表現できていること、御成敗式目全体に矛盾がないことを保証するものではありません。歴史的な運用や実際の裁定を判断するには、裁判記録・追加法・当時の通達との照合が必要です。
